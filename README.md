## Install

### Get git

```bash
nix-shell -p git
```

### Clone or fork the repository to `~/.config/`

```bash
export FLAKE_PATH="~/.config/nixos"
git clone https://github.com/oscar370/nixos.git ${FLAKE_PATH}
cd ${FLAKE_PATH}
```

### Run `setup-hardware-config.sh` to copy your hardware configuration

```bash
./setup-hardware-config.sh
```

> If you change your hardware (including changing the mounting of external drives), run the script again. You can read more [here](https://wiki.nixos.org/wiki/Nixos-generate-config).

### Configure the files to your liking (username, packages, etc.)

Check out the [Config section](#config) to learn about the folder structure.

### Build the flake

```bash
sudo nixos-rebuild boot --flake ${FLAKE_PATH}
```

## Config

The configuration is split into a desktop-independent core and a desktop layer, so the desktop can be swapped without touching the core.

### Entry point

`flake.nix` defines the inputs, the username and the modules that make up the system. The desktop is chosen here: `host/gnome.nix` for the system and `home/gnome.nix` for the user. To use another desktop, replace both lines.

### System (`host/`)

- `configuration.nix`: desktop core.
- `gnome.nix`: GNOME, GDM, etc.
- `hardware-configuration.nix`: generated by `setup-hardware-config.sh`, including the architecture (`nixpkgs.hostPlatform`).

### Home (`home/`)

- `home.nix`: user packages and settings.
- `xdg.nix`: user directories and variables that keep `$HOME` clean (suggested by `xdg-ninja`).
- `gnome.nix`: GNOME settings.

> Use the `configuration.nix` generated by NixOS during installation as a reference.
